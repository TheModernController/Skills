# The Modern Controller: Skills

Free Claude skills from [The Modern Controller](https://www.youtube.com/@TheModernController) on YouTube. Each one automates a piece of month-end work, while the accountant keeps the review and the decisions.

| Skill | Version | Video | Download |
| --- | --- | --- | --- |
| [Bank reconciliation](bank-reconciliation/README.md) | 0.5.1 | Day 1 of the Month-End Automation series | [bank-reconciliation-0.5.1.zip](https://github.com/TheModernController/Skills/raw/main/bank-reconciliation/bank-reconciliation-0.5.1.zip) |

**Download the skill ZIP from the table, not GitHub's green Code > Download ZIP button.** That button downloads this whole repository, and Claude can't install it.

Each skill folder has setup instructions, the skill's readable source, and fictional example files to practise on.

All example data is fictional. The skills propose journal entries and reconciliations for an accountant to review. They don't post anything to your accounting system.
